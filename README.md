Sistema web de organização financeira pessoal desenvolvido em HTML, CSS e JavaScript puro.

Projeto criado com foco em aprendizado de desenvolvimento web, organização de código e experiência do usuário.

Tecnologias utilizadas:

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Chart.js
- PWA
- Service Worker

A ideia do projeto é permitir que o usuário controle receitas, despesas, contas, cartões, metas financeiras e acompanhe sua situação financeira de forma simples e organizada.

## Demonstração

Aplicação online:

https://dourado-financas-app.netlify.app/

## Funcionalidades

Atualmente o sistema possui:

- Dashboard financeiro
- Cadastro de receitas
- Cadastro de gastos fixos
- Cadastro de gastos variáveis
- Histórico de lançamentos
- Pesquisa, filtros e ordenação
- Contas bancárias
- Transferências entre contas
- Cartões de crédito
- Controle de faturas
- Categorias personalizadas
- Caixinhas com metas
- Barra de progresso das metas
- Guardar e resgatar dinheiro
- Lançamentos recorrentes
- Relatórios financeiros
- Backup e restauração dos dados
- Interface responsiva
- Instalação como aplicativo (PWA)

## Como executar

Clone o repositório:

```bash
git clone https://github.com/DouradoArthurSilva/dourado-financas.git
```

Depois abra a pasta no Visual Studio Code.

Para utilizar corretamente o Service Worker e o PWA, execute o projeto utilizando a extensão Live Server ou publique em um servidor como Netlify.

## Armazenamento

Os dados são armazenados utilizando o LocalStorage do navegador.

Caso o navegador seja limpo ou os dados sejam apagados, as informações serão perdidas. Por isso existe uma tela de backup para exportar e restaurar os dados quando necessário.
